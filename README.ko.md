# 제로 아이템(Zero-Item) 입시 보안 프로토콜(안)

**한국어 · [English](README.md)**

일본을 예시로, 대학 입학시험에서 전자기기(스마트글래스·초소형 이어폰·AI)를 이용한 부정행위를 막기 위한 보안 프로토콜(안)입니다.

시험 건물을 "보안 구역"으로 지정하고, 입구에서 1회 검사한 뒤 시험 종료까지 검사받지 않은 물품의 반입을 차단합니다. 시스템은 감독관을 대체하지 않고 뒷받침합니다.
