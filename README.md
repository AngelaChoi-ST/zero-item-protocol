# Zero-Item Security Protocol (Draft)

**[한국어](README.ko.md) · English**

A draft protocol for preventing device-assisted cheating (smart glasses, micro earpieces, AI) in university entrance examinations, using Japan as the example.

The examination building is designated a "secure zone". After a single screening at the entrance, no unscreened item may enter until the examination ends. The system supports proctors; it does not replace them.
